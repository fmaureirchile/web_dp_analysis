# Prompt de Etapa 0 - Constitucion del producto

## Objetivo

Definir de forma no ambigua que es y que no es la plataforma antes de iniciar codigo productivo.

## Prompt

Implementa exclusivamente la Etapa 0: constitucion del producto.
No avances a Etapa 1.

Entregables obligatorios:
1. Documento de vision.
2. Alcance y exclusiones.
3. Glosario del dominio.
4. Mapa de actores.
5. Casos de uso iniciales.
6. Matriz de modalidades de evaluacion.
7. Politica de uso autorizado y salvaguardas.
8. Registro inicial de riesgos.
9. Severidades iniciales para observaciones y discrepancias.

Reglas:
1. Diferenciar estrictamente:
   - Hecho tecnico observado.
   - Evidencia de informacion o consentimiento.
   - Conclusion juridica.
2. No declarar licitud o ilicitud automaticamente.
3. Definir niveles de evidencia E1, E2 y E3 como base minima:
   - E1: evidencia estatica o documental.
   - E2: evidencia dinamica observable en ejecucion.
   - E3: evidencia validada por revision humana.
4. Definir taxonomia inicial de datos personales con confianza y trazabilidad.

Criterio de salida:
No se puede comenzar Etapa 1 hasta cerrar ambiguedades sobre:
1. Acciones permitidas del escaner.
2. Evidencia a conservar.
3. Regla para convertir observacion en hallazgo.
4. Limite entre salida tecnica y conclusion juridica.
