# Prompt de tarea - E0-T01 Vision y limites del producto

Implementa exclusivamente la tarea E0-T01 de la Etapa 0.

Objetivo unico:
Definir vision del producto, problema a resolver, valor principal y no-objetivos.

Dependencias:
Ninguna.

Contratos vigentes:
- Prompt Maestro Permanente.
- Prompt de Etapa 0.

Archivos permitidos:
- docs/etapa-0/vision-producto.md
- docs/etapa-0/alcance-exclusiones.md

Archivos prohibidos:
- Cualquier carpeta de codigo de Etapa 1 en adelante.

Entradas:
- Requisitos de Antecedentes.
- Roadmap.

Salidas:
- Vision del producto con limites explicitos.
- No-objetivos y restricciones.

Casos de error:
1. Vision ambigua sin no-objetivos.
2. Mezcla de conclusiones juridicas con observaciones tecnicas.
3. Alcance que permite acciones no autorizadas.

Criterios de aceptacion:
1. Incluye declaracion explicita de lo que la plataforma no hara.
2. Distingue hecho tecnico, evidencia y conclusion juridica.
3. Permite validar si se puede pasar a E0-T02.

Pruebas obligatorias:
1. Checklist de ambiguedades de alcance.
2. Revision de consistencia terminologica con glosario preliminar.

Restricciones:
- No implementar tareas posteriores.
- No crear estructura de Etapa 1.
- No introducir conclusiones juridicas automaticas.

Entrega final requerida:
1. Resumen.
2. Archivos modificados.
3. Pruebas aplicadas.
4. Limitaciones.
5. Confirmacion de que no se avanzo a otra tarea.
