## 2) Alcance y exclusiones

- Modalidades excluidas:

- Acciones tecnicas prohibidas:

## 3) Glosario

Para cada termino:
- Termino:
- Definicion operativa:
- Ejemplo:
- Termino relacionado:
- Uso prohibido o ambiguo:

## 4) Mapa de actores

Para cada actor:
- Actor:
- Objetivo:
- Permisos:
- Restricciones:
- Evidencias que puede consultar:

## 5) Matriz de modalidades

Columnas sugeridas:
- Modalidad.
- Requiere autenticacion.
- Permite formularios.
- Permite credenciales.
- Limite de requests.
- Limite de concurrencia.
- Evidencia minima.
- Riesgo residual.

## 6) Niveles de evidencia

Para cada nivel:
- Codigo (E1/E2/E3).
- Fuente.
- Metodo de captura.
- Reproducible (si/no).
- Riesgos de sesgo.
- Uso permitido en reporte.

## 7) Taxonomia inicial y severidades

Para cada categoria de dato:
- Categoria.
- Subcategoria.
- Sensibilidad.
- Confianza minima.
- Evidencia requerida.
- Severidad tecnica sugerida.

## 8) Registro inicial de riesgos

Para cada riesgo:
- ID.
- Descripcion.
- Tipo (tecnico/seguridad/privacidad/operacion).
- Impacto.
- Probabilidad.
- Mitigacion.
- Responsable.
- Estado.

## 9) Criterio de cierre de etapa

Checklist:
- Existe diferenciacion entre hecho, evidencia y conclusion juridica.
- No hay conclusiones juridicas automaticas.
- Se definieron salvaguardas operativas.
- Se definio evidencia minima por observacion.
- Existe criterio para pasar a Etapa 1.
