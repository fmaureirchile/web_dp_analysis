# Criterio de salida de Etapa 0

La Etapa 0 se considera cerrada solo si todos los puntos siguientes estan completos y consistentes.

## Checklist de cierre

1. Vision del producto aprobada con no-objetivos explicitos.
2. Alcance y exclusiones sin ambiguedades operativas.
3. Glosario inicial definido y sin terminos duplicados criticos.
4. Mapa de actores y separacion de funciones documentados.
5. Modalidades de evaluacion y salvaguardas definidas.
6. Politica de uso autorizado formalizada.
7. Niveles de evidencia E1/E2/E3 y trazabilidad minima definidos.
8. Taxonomia inicial y severidades tecnicas documentadas.
9. Registro inicial de riesgos con mitigaciones y responsables.
10. Regla explicita de no conclusion juridica automatica.

## Gate para iniciar Etapa 1

No iniciar Etapa 1 mientras exista alguna duda en:
1. Que acciones puede ejecutar el escaner.
2. Que evidencia debe conservarse y con que metadatos.
3. Cuando una observacion puede escalar a hallazgo.
4. Como separar observacion tecnica de conclusion juridica.

## Resultado esperado de cierre

- Estado: APTO PARA ETAPA 1.
- Evidencia documental: completa.
- Riesgos residuales: identificados y aceptados por responsables.
