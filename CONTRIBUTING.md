# Contribucion

## Flujo recomendado

1. Crear rama por tarea (ejemplo: feat/e1-t01-monorepo).
2. Mantener alcance estricto por etapa/tarea.
3. Ejecutar lint, typecheck y tests antes de PR.
4. Abrir PR usando la plantilla oficial.
5. Registrar decisiones relevantes en ADR.

## Convencion de commits

Formato:
- tipo(scope): descripcion breve

Tipos:
- feat
- fix
- docs
- test
- refactor
- chore

Ejemplos:
- feat(etapa-1): crear estructura base de monorepo
- docs(etapa-0): cerrar acta de revision de coherencia
