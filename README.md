# Web Analysis - Analizador para proteccion de datos (Chile)

Este repositorio parte desde la metodologia de prompts secuenciales para construir, por etapas, una plataforma de descubrimiento y evaluacion de captura de datos personales en aplicaciones web, alineada con la Ley N. 21.719.

## Objetivo de esta base

- Ejecutar desarrollo por etapas sin mezclar alcances.
- Evitar conclusiones juridicas automaticas.
- Mantener trazabilidad completa entre observacion y evidencia.
- Permitir revision humana antes de confirmar hallazgos.
